# Interface Gráfica com Placeholder Automático em Tkinter

Este projeto é uma demonstração prática de manipulação de eventos e construção de interfaces gráficas desktop utilizando a biblioteca **Tkinter** em Python. O projeto serve como base/módulo inicial para aplicações maiores que demandem validações de entrada e componentes visuais interativos.

## 🚀 Funcionalidades

- **Placeholder Dinâmico:** Dica visual (`"Digite seu nome aqui..."`) que desaparece ao focar no campo (`<FocusIn>`) e reaparece se o campo estiver vazio ao perder o foco (`<FocusOut>`).
- **Validação Básica:** Trata o envio de campo vazio ou não alterado, alterando dinamicamente as cores das mensagens.
- **Feedback ao Usuário:** Exibe mensagens de boas-vindas ou de alerta de acordo com o preenchimento.

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Tkinter** (Biblioteca padrão do Python para GUI)
